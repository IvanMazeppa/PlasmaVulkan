# Companion Guide for CRs 1012–1014 (2025-09-14)

Objective
- Achieve RTX self-shadowing for the mesh particle cloud by ray-querying against iso-surface shells extracted from a coarse density grid.

Execution order
- 1012_density_grid_from_particles
- 1013_extract_iso_surface_shells
- 1014_mesh_rt_self_shadow_apply

General rules
- Keep transitions outside dynamic rendering; use Synchronization2 barriers between compute/graphics.
- Maintain mesh and volume paths separately; shells are mesh-RT occluders only.

---

## 1012 — Low-res density grid from particles

Tips
- Resolution: start 96^3 or 128^3; R16_SFLOAT is sufficient. Fit grid to particle AABB each frame or with hysteresis.
- Splat kernel: box or small Gaussian; avoid oversaturation by clamping per-voxel contributions.
- Mips: build a few levels to support threshold selection and potential filtering.
- Layouts: GENERAL for compute writes; SHADER_READ_ONLY_OPTIMAL for reads; avoid transitions inside rendering.

Acceptance
- Grid updates every frame; average density > 0 with particles present; no validation errors.

MCP queries
- search_vulkan_spec("3D image layout transitions with Synchronization2")
- search_vulkan_spec("vkCmdBlitImage 3D mip generation requirements")

---

## 1013 — Iso-surface shells (marching cubes)

Tips
- Thresholds: pick 1–3 values spanning low/medium/high density percentiles. Start with one shell.
- Implementation: CPU marching cubes is fine initially; allocate device-addressable vertex/index buffers.
- BLAS: triangle geometry; query sizes, build with a transient scratch; keep BLAS persistent and refit or rebuild when thresholds/grid change.
- TLAS: instance each shell; identity transform; log triangle counts and TLAS device address.

Acceptance
- BLAS for shells built with non-zero triangles; TLAS updated; no build-time VUIDs.

MCP queries
- search_vulkan_spec("VkAccelerationStructureGeometryTrianglesDataKHR")
- search_vulkan_spec("vkGetAccelerationStructureBuildSizesKHR")
- search_vulkan_spec("vkCmdBuildAccelerationStructuresKHR")

---

## 1014 — Apply RT occlusion in mesh fragment

Tips
- Direction: use the directional light from 1005; cast along -lightDir.
- Ray query: TerminateOnFirstHit|Opaque; one query per fragment; early-out on tiny alpha to reduce cost.
- Modulation: start hard (shadowVis=0 on hit) for clear validation; soften later (1008) or scale to 0.2–0.5.
- Toggle: guard with a runtime flag (rtSelfShadow) for quick bisecting.

Acceptance
- Visible self-shadowing over the particle cloud with RT enabled; no new validation errors.

MCP queries
- search_vulkan_spec("GL_EXT_ray_query")
- search_vulkan_spec("Ray query flags and intersection semantics")

---

Debug flow
- If shells produce no effect: verify thresholds, triangle counts, TLAS device address, and that binding 3 (AS_KHR) is pushed in the mesh pass.
- If performance is low: reduce shell count or grid resolution; skip ray queries on low-alpha fragments.
- After validation, add softening (1008) and optional temporal stabilization.
