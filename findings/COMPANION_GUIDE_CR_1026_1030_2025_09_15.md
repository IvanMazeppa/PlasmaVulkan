### Companion Guide: Mesh RT Stability (CR 1026–1030)

Symptoms in log
- 08114: Binding 4 (shell TLAS) reported as used but never updated on draw.
- 09600: Coarse image mips expected GENERAL vs currently SHADER_READ_ONLY_OPTIMAL (and vice versa) during mesh draws.
- 10069: SPH mesh pipeline push-constant block exceeds layout range during creation.
- App “disappears” when entering mesh mode likely due to repeated validation and undefined behavior around statically used but unbound binding 4, plus shifting coarse image layouts.

Root causes
- Single mesh pipeline statically references binding 4 in the fragment shader even when shell TLAS is not ready, triggering descriptor validity checks.
- Coarse image transitions flip per frame without keeping descriptor-written layout consistent with actual sampling layout in the mesh pass.
- SPH pipeline push-constant range too small for the shader’s block (fragment stage path).

Apply in this order
1) 1026_dual_mesh_pipelines.json — Two pipelines: ext-only (no binding 4) and ext+shell (binding 4). Pick per-frame.
2) 1029_rt_ready_state.json — Drive pipeline choice by a simple readiness state machine; log pipeline and descriptor count.
3) 1028_coarse_layout_guard.json — Keep coarse mips in a stable, expected layout; stop flipping during graphics.
4) 1027_push_constants_unify.json — Expand push-constant ranges to cover struct sizes.
5) 1030_sph_pc_fix.json — Fix or gate SPH pipeline creation until stable.

Verification
- On first frames of mesh mode: logs show “pipeline=ext descriptors=2 (particle_buffer external_TLAS)”. No 08114.
- When shell TLAS becomes ready: logs show “pipeline=ext+shell descriptors=3 (… shell_TLAS)”. No 08114.
- No 09600 spam once coarse image descriptor layout equals the actual subresource layouts sampled by mesh.
- No 10069 during mesh/SPH pipeline creation.

MCP queries
- search_vulkan_spec('statically used descriptors binding validation 08114')
- search_vulkan_spec('image layout must match descriptor layout 09600')
- search_vulkan_spec('push constant range must cover shader block 10069')

Notes
- Ensure the ext-only pipeline’s layout excludes binding 4 entirely. The fragment shader variant must compile without declaring binding 4.
- Keep coarse image transitions in compute path; end in the layout that the mesh shader samples from, and write descriptors with that same layout.
- Throttle status logs to 1–2s cadence to reduce noise.
