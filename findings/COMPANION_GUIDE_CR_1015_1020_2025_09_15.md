# Companion Guide: Stabilizing Shell TLAS and Enabling Self-Shadows (CR 1015–1020)

Goal
- Fix TLAS build crashes and make self-shadowing visible and debuggable in mesh mode.

Primary findings from logs/results
- AS scratch buffers missing VK_BUFFER_USAGE_STORAGE_BUFFER_BIT (VUID 03674) → invalid scratch device addresses during vkCmdBuildAccelerationStructuresKHR.
- Coarse density image repeatedly transitions with wrong oldLayout for higher mips (VUID 01197) and draw-time layout mismatches (VUID 09600).
- Shell TLAS is not bound at render time (logs: "Pushed 2 descriptors: particle_buffer external_TLAS"), so no self-shadow effect.
- Exit-time leaks for buffers/images indicate missing RAII around shell resources.

Execution plan (apply in order)
1) CR 1015 — Fix AS scratch usage/sizing
2) CR 1019 — Correct coarse grid layouts/mips
3) CR 1016 — Add TLAS rebuild synchronization
4) CR 1017 — Bind shell TLAS + instrumentation
5) CR 1018 — Ray query masks + overlay
6) CR 1020 — RAII cleanup

---

## CR 1015 — Fix AS scratch usage/sizing
Symptoms
- VUID 03674 spam during BLAS/TLAS builds; intermittent crashes.
Key actions
- Create scratch buffers with STORAGE_BUFFER | SHADER_DEVICE_ADDRESS.
- Size via vkGetAccelerationStructureBuildSizesKHR; respect minAccelerationStructureScratchOffsetAlignment.
Acceptance
- No VUID 03674; stable AS builds across multiple rebuilds.
MCP queries
- search_vulkan_spec("VUID-vkCmdBuildAccelerationStructuresKHR-pInfos-03674")
- get_vulkan_entity("vkGetAccelerationStructureBuildSizesKHR")
- get_vulkan_entity("VkPhysicalDeviceAccelerationStructurePropertiesKHR")

## CR 1019 — Coarse grid layouts/mips
Symptoms
- VUID 01197 and VUID 09600 for mips 1..6; invalid oldLayout and draw-time mismatch.
Key actions
- One-time init: clear all mips → SHADER_READ_ONLY_OPTIMAL.
- Per-frame: 0: GENERAL → TRANSFER_SRC for blits → all mips to SHADER_READ_ONLY_OPTIMAL; track per-mip layout.
Acceptance
- No VUID 01197/09600; grid samples valid.
MCP queries
- search_vulkan_spec("Synchronization2 image layout transitions with mip levels")
- get_vulkan_entity("vkCmdBlitImage")

## CR 1016 — TLAS rebuild synchronization
Symptoms
- Crash when shell TLAS rebuild executes (race vs render).
Key actions
- Timeline semaphore: extract → BLAS → TLAS → render wait chain.
Acceptance
- No crashes during periodic rebuilds; logs show waited timeline value.
MCP queries
- get_vulkan_entity("VkSemaphoreTypeCreateInfo")
- get_vulkan_entity("VkSubmitInfo2")
- get_vulkan_entity("VkSemaphoreSubmitInfo")

## CR 1017 — Bind shell TLAS + instrumentation
Symptoms
- No shell TLAS bound (only external TLAS pushed); no self-shadows.
Key actions
- Add binding_4 AS; push both AS descriptors; print device addresses at draw.
- Shader-side guard: signal when binding_4 is null.
Acceptance
- Logs show "Pushed 3 descriptors: ... shell_TLAS"; non-zero address.
MCP queries
- get_vulkan_entity("VkWriteDescriptorSetAccelerationStructureKHR")
- search_vulkan_spec("Push descriptors acceleration structure KHR")

## CR 1018 — Ray query masks + overlay
Symptoms
- Hard to tell if rays hit shells; no visible effect.
Key actions
- Instance masks: external=0x01, shells=0x02; self-shadow queries use cullMask=0x02.
- Overlay: color by hit distance; runtime toggles.
Acceptance
- Overlay reveals hit/no-hit patterns; isolating masks works.
MCP queries
- get_vulkan_entity("VkAccelerationStructureInstanceKHR")
- search_vulkan_spec("rayQuery cullMask semantics")

## CR 1020 — RAII cleanup
Symptoms
- Exit-time VUID 05137 for live buffers/images.
Key actions
- RAII wrappers and deterministic destroy order; asserts on leaks.
Acceptance
- No exit-time VUIDs; clean shutdown.
MCP queries
- search_vulkan_spec("Object lifetime and destruction order requirements")

Verification checklist
- Scratch buffer logs show valid usage flags and aligned sizes.
- Coarse grid state line per frame shows all mips in SRO post-update.
- Timeline value printed by render >= value signaled by TLAS build.
- Render log: "Pushed 3 descriptors: particle_buffer external_TLAS shell_TLAS".
- Overlay shows self-shadow hits when masks target shells.
- Shutdown prints zero live resources.
