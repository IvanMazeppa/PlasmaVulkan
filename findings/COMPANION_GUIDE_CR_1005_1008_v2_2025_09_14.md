# Companion Guide for CRs 1005–1008 (v2, 2025-09-14)

This guide augments the change requests with practical implementation details, pitfalls, acceptance checks, and MCP queries.

Applies to (in execution order)
- 1005_light_controls_and_occlusion_debug
- 1006_occluder_bounds_overlay
- 1007_exit_time_vuid_cleanup
- 1008_shadow_quality_softening_and_temporal

General rules
- No barriers/copies inside dynamic rendering blocks. Place transitions before/after `vkCmdBeginRendering`/`vkCmdEndRendering`.
- Keep mesh and volume descriptor sets/pipelines decoupled. Only mesh path gets binding 3 = AS_KHR.
- Use Sync2 barriers; prefer `vkQueueSubmit2`/`vkCmdPipelineBarrier2`.

## 1005 — Directional light + occlusion amplify

Tips
- Light state can live in push constants if small (direction vec3, intensity float, flags). Otherwise a tiny UBO.
- For billboards, approximate normal with view-facing: compute in mesh shader or fragment as normalized vector towards camera.
- Occlusion apply: `finalColor *= mix(1.0, shadowVis, shadowWeight)`; for debug amplification set `shadowWeight > 1` or apply `shadowVis *= shadowVis` to exaggerate.
- Keyboard controls: store spherical angles and rebuild direction each frame. Throttle console prints (~0.2–1.0s) to avoid spam.

Acceptance
- With RT enabled and amplify ON, rotating the light moves a clearly visible dark region across the particle cloud.

MCP queries
- search_vulkan_spec("push constants pipeline stages")
- search_vulkan_spec("descriptor updates and image layout consistency")

## 1006 — Occluder bounds overlay (placement verification)

Tips
- Use instance transform (row-major 3x4). Convert to a 4x4 for rendering the box. Precompute object-space AABBs.
- Draw lines with a minimal pipeline (depth test off to guarantee visibility). Toggle key B to show/hide.
- Print instance transforms and resulting world-space AABB once after build and on transform change.

Acceptance
- Overlay boxes tightly wrap occluders and match printed AABBs.

MCP queries
- search_vulkan_spec("VkAccelerationStructureInstanceKHR transform row-major")

## 1007 — Exit-time VUID cleanup

Tips
- Build a small debug-only tracker for VkImage, VkImageView, VkBuffer, VkDeviceMemory (or VMA allocations), VkAccelerationStructureKHR, VkPipeline, VkPipelineLayout, VkDescriptorPool, VkDescriptorSetLayout.
- Teardown order: pipelines/descriptors → AS (TLAS → BLAS) → image views → images → buffers → memory → swapchain → device.
- Swapchain images are owned by the swapchain; destroy views, not images. Free VkDeviceMemory for manually allocated resources.

Acceptance
- No 05137 VUIDs on 3 clean exits; shutdown summary shows destroyed counts per type.

MCP queries
- search_vulkan_spec("Object lifetime and destruction order")
- search_vulkan_spec("vkDestroyDevice children must be destroyed")

## 1008 — Soft RT shadows (jitter + temporal)

Tips
- Jitter: build an orthonormal basis around lightDir; sample a tiny cone (≈1–2°). Per-pixel hash seeded by frameIndex+pixelCoord or use STBN.
- Temporal: accumulate visibility in an R8/R16 target; `vis_accum = clamp(mix(prev, curr, 0.1), prev-0.25, prev+0.25)`. Reset on resize or toggle change.
- Keep one ray-query per fragment; optionally interleave two directions every other frame.

Acceptance
- Penumbrae appear; shimmer reduced; stable under motion with minimal ghosting.

MCP queries
- search_vulkan_spec("GL_EXT_ray_query")
- search_vulkan_spec("VkImageLayout for sampled images during postprocess")

Debug flow
- After 1005: if no visual change, ensure RT is enabled, toggle amplify, then use 1006 overlay and rotate light to confirm occluders intersect the cloud along the light direction.
- After 1007: if any exit-time VUIDs remain, print resource counts and identify the owner subsystem; add missing destroy calls.
- After hard shadows are clearly visible and clean shutdown is verified, apply 1008 for softening and temporal stability.
