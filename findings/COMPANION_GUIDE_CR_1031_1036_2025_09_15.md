### Companion Guide: Mesh Visibility + Crash Fixes (CR 1031–1036)

What you’re seeing
- Split artifact that looks like two renderers active at once (one half denser/flat plane).
- App runs a few frames, then freezes/exits.
- Log shows persistent 09600 on coarse mip 0 despite earlier layout work and repeated coarse updates.

Root causes
- Both renderers are being executed in the non-volumetric path: the mesh path and the legacy point-sprite path. See `Application::recordCommandBuffer` — point sprites render when mesh shaders are not gated out.
- Residual coarse layout mismatch: descriptor layout and actual layout for mip 0 still diverge around mesh draw time.
- Excessive per-frame coarse updates/extractions flood validation and GPU, increasing the chance of stalls.

Apply in this order
1) 1031_mesh_only_guard — Enforce exclusive rendering (mesh-only) to remove the split plane immediately.
2) 1033_coarse_layout_fixup — Lock the sampled layout (prefer GENERAL) and ensure descriptors match; stop flipping every frame.
3) 1036_crash_guard_yield — Throttle coarse updates and shell extraction cadence.
4) 1032_ext_only_depth_blend — Ensure parity of depth/blend states between ext-only and full mesh pipelines.
5) 1035_particle_draw_state — Ensure both renderers (when tested independently) use identical viewport/scissor and additive blend.
6) 1034_mesh_pipeline_selection_log — Add per-frame (throttled) confirmation of pipeline and descriptor count.

Verification checklist
- First mesh frames: log shows “Mesh-only mode: enabled”; point-sprite path not hit. No split plane in screenshots.
- No VUID-09600 lines. Coarse update messages are throttled, not per-frame spam.
- Pipeline debug: “pipeline=ext descriptors=2” before shells; switches to “pipeline=ext+shell descriptors=3” when ready.
- No freeze/exits over 30+ seconds of runtime.

MCP queries
- search_vulkan_spec('draw state parity depthWrite blend additive')
- search_vulkan_spec('descriptor image layout must match actual subresource 09600')
- search_vulkan_spec('Submit cadence and synchronization best practices Synchronization2')

Notes
- Prefer GENERAL for coarse sampling to keep storage and sampling unified; write descriptors with GENERAL and do not revert to SHADER_READ_ONLY_OPTIMAL in the mesh path.
- When testing the legacy renderer, temporarily disable mesh to compare visuals without interference.
